# SRC-06 + SRC-10 — Import local M3U file, delete all local data

**Status:** In review (2026-10-29) · agent `implementer` (worktree, branch `story/SRC-06`)

## Delivered
- **SRC-06:** "Local M3U file" in onboarding and in the My lists "Add list" chooser (`/onboarding/m3u-file`, `/settings/sources/add/m3u-file`); replaces the "coming soon" placeholder. The URL form's CORS / mixed-content failure now links to it.
  - File picker (`accept=".m3u,.m3u8,audio/x-mpegurl,application/vnd.apple.mpegurl"`); the `File` goes to the data worker by structured clone (task `syncM3uFile`) and is read with `file.stream()` (`providers/m3u/readFile.ts`) through the same streaming parser, VOD-04 classification, single-transaction write, progress (phase `read`), cancellation and search index rebuild hook as URL lists.
  - Over 50 MB (decimal, as sizes are shown): time/memory warning and confirmation, both when adding and when refreshing. Over `MAX_BYTES` (512 MB): `too-large` before reading.
  - The source row has no URL and nothing in the vault; the file is never stored (only the parsed catalogue). New error code `file-unreadable` (moved/deleted/changed file).
  - "Refresh" on a file list opens a dialog asking for the updated file (`startSourceSync(..., { file })`).
  - Shared import state/views of both M3U forms extracted to `features/sources/m3u/importState.tsx`.
- **SRC-10:** Settings › Privacy and data › "Delete all data": dialog with the localized confirmation word (`DELETE` / `APAGAR`, from i18n; case and surrounding spaces ignored), progress, then a reload on `#/onboarding`. Partial failure lists what was not deleted (database / cached files / browser preferences) and offers "Try again".
  - Order: terminate the data worker (its DB connection, sync and search index cache) → delete the `simple-iptv` database (vault secrets and device key included; 10 s timeout when another tab blocks it) → caches → Web Storage → log redactor secrets and buffer → reload (resets every in-memory store: active list, playback flags, sources presence, language, theme).
  - **Cache decision (AC2):** the app-shell precache (`workbox-precache-*` of this scope) is kept — build files only, no user data, and deleting it would break offline start until the next app update. Every other cache whose name carries this app's scope is deleted. Caches and Web Storage keys of other apps on the same origin (GitHub Pages user site) are left alone; only `simple-iptv:*` keys and React Router's scroll positions are removed. The service worker registration is not touched.
