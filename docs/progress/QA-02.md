## Decisions
- axe only in Chromium (both viewports): rules depend on DOM and computed styles, not the engine; Firefox was 2× slower with one worker and hit the 3-minute timeout under parallel load. Firefox/WebKit run the smoke flows.
- Playback assertion: the stream request is always asserted; "Playing" only in Chromium. Playwright's Firefox build has no H.264/AAC decoders and shows "Format or codec not supported" (which offers "Next channel", so zapping still runs).
- axe `target-size` nodes reported as "partially obscured" are ignored: they are rows scrolled under the fixed phone bottom bar.
- Tablet viewport (820×1180) from TEST_PLAN §1 not added (cost of a full browser pass).

## Defects found (not fixed; reproduction steps)
1. **UX-06 AC2 — navigation labels do not switch language without a reload.** Add a list → Settings → Language → Português: headings and the nav landmark name change ("Navegação principal") but the rail/bottom-bar links stay "Home, Live, Movies, Series, Favorites, Settings" until reload. Cause: `src/app/shell/navItems.tsx` evaluates `t.nav.*` at module load. Covered by `smoke.spec.ts` "UX-06 AC2…" marked `test.fail()`.
2. **EPG-01 — short-EPG request loop.** Add the synthetic Xtream list → Live: `get_short_epg` for stream 1001 is requested continuously (measured: 81 requests in 5 s, 523 in 3 s), because all its programmes (2026-01-01) have ended and `fresh()` in `src/features/live/epg.ts` never considers such an entry fresh. A provider with stale EPG would get the same flood. Covered by `live-epg.spec.ts` marked `test.fail()` (Chromium).
3. **a11y (fixed, one-liners):** Settings › Lists and › Privacy rendered `<ul>` with `<a>` children (axe `list`, serious). `List component="div"` in `SourcesSection.tsx` and `PrivacySection.tsx`.
