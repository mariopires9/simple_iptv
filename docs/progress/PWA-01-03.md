# PWA-01, PWA-02, PWA-03 — Installable app, app-shell service worker, predictable updates

**Status:** Done (2026-10-29) · agent `implementer` (worktree) · reviews: `/code-review`, security review

## Delivered
- PWA-01: `vite-plugin-pwa@2.0.0` (generateSW); manifest (name, start_url/scope/id = base, standalone, token colours, 192/512 + maskable icons, placeholder screenshots); iOS apple-touch-icon and meta; Install app section in Settings (`beforeinstallprompt` captured at boot, iOS "Share → Add to Home Screen" steps, installed/dismissed states). Original icons generated by `scripts/generate-pwa-assets.mjs`.
- PWA-02: precache of same-origin app shell only (123 entries, ~1.6 MB; hls.js/mpegts.js engines excluded — first play only; `licenses.json` included). No runtime caching, no navigation fallback. `scripts/check-dist-sw.mjs` runs in `npm run build` and fails on any cross-origin/credential-like precache entry, runtime route, engine chunk or wrong manifest base.
- PWA-03: prompt-mode SW; "New version available — Update" toast; never applied automatically and withdrawn while a player is open (`claimPlayback` in `@/core/session/playback`); Update = SKIP_WAITING + reload on the same route; idle tabs reload when another tab updates, tabs with a player keep playing; update checks on visibility (≤ 1/min) and hourly. Startup indicator "Preparing your data…" while the database opens (> 300 ms).
