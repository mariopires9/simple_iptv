## How to run
1. `npm run dev`
2. Open `http://localhost:5173/spikes/compat/` in Chrome (and, if possible, Firefox).
3. Enter server, username and password (kept only in memory on that page).
4. "1. Test API" → then "2a", "2b" and "2c" (unmute the player to confirm audio).
5. Copy the **Report** (already masked) and paste it into the conversation.

## Test limitations
- On `http://localhost` there is no mixed-content blocking; the report states deterministically whether the server will be blocked in the published app (HTTPS).
- Phones (Android/iPhone) can only be tested once an HTTPS page exists (DEP-01) — deferred to DEP-02.
