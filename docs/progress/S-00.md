# S-00 — Validar compatibilidade do fornecedor real

**Estado:** In Progress — a aguardar execução pelo utilizador.

## Como executar
1. `npm run dev`
2. Abrir `http://localhost:5173/spikes/compat/` no Chrome (e, se possível, Firefox).
3. Introduzir servidor, utilizador e palavra-passe (ficam só em memória nessa página).
4. "1. Testar API" → depois "2a", "2b" e "2c" (ativar o som no leitor para confirmar áudio).
5. Copiar o **Relatório** (já mascarado) e colá-lo na conversa.

## Limitações do teste
- Em `http://localhost` não há bloqueio de mixed content; o relatório indica de forma determinística se o servidor será bloqueado na app publicada (HTTPS).
- Telemóveis (Android/iPhone) só podem ser testados depois de existir uma página HTTPS (DEP-01) — fica para DEP-02.
