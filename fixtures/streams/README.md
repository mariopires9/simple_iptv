# Test streams

Synthetic media used by player tests (QA-01). Everything here was generated by
`scripts/fixtures/generate-streams.sh` from ffmpeg's built-in `testsrc2` video
pattern and `sine` audio tone. No third-party or provider media is included.

**Licence:** generated test patterns, dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

All files: 320×180 @ 25 fps, 5 s, H.264 Main 3.0 (`avc1.4d401e`), keyframe every 2 s.

| Path                               | Content                                                                                                                 | Purpose                                     |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `hls/index.m3u8` + `seg*.ts`       | HLS VOD, H.264 + AAC-LC mono (440 Hz), 2 s TS segments                                                                  | Basic HLS playback                          |
| `hls-multi/master.m3u8`            | Video-only variant + audio renditions `en` (440 Hz) / `pt` (660 Hz) + WebVTT subtitle rendition `en` (`subs/en.m3u8`)   | Audio track / subtitle selection (PLY-05)   |
| `ts/h264-aac.ts`                   | MPEG-TS, H.264 + AAC-LC (stream types 0x1B / 0x0F)                                                                      | Xtream-style live `.ts` (mpegts.js)         |
| `ts/h264-ac3.ts`                   | MPEG-TS, H.264 + AC-3 stereo 96 kb/s (stream types 0x1B / 0x81)                                                         | Unsupported audio codec path (PLY-04)       |
| `mp4/h264-aac.mp4`                 | Progressive MP4, `+faststart` (moov before mdat), H.264 + AAC-LC                                                        | Native `<video>` / VOD                      |

Serve them locally with `node scripts/test-stream-server.mjs --port 8090 --cors on`
(supports Range requests and `/slow/`, `/error500/`, `/redirect/`, `/auth401/` path prefixes).

To regenerate: `scripts/fixtures/generate-streams.sh` (uses `$FFMPEG`, `ffmpeg` on PATH,
or a throwaway install of the `ffmpeg-static` npm package). Output is byte-identical
across runs with the same ffmpeg build.
